# Тест скорости интернета

Консольный скрипт для замера скорости скачивания: делает N последовательных
запросов к указанному URL, дожидается полной загрузки ответа на каждый,
и печатает среднее время запроса, суммарный объём и скорость.

## Требования

- Python 3.8+
- Внешних зависимостей нет (только стандартная библиотека)

## Запуск

```bash
python speedtest.py <URL> [-n 10] [-t 30]
```

| Флаг | Описание | По умолчанию |
|------|----------|--------------|
| `-n, --count` | Количество последовательных запросов | `10` |
| `-t, --timeout` | Таймаут на один запрос, сек | `30` |

Пример:

```bash
python speedtest.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

## Единицы измерения

- **Время** — секунды (`с`).
- **Скорость** — `Кбит/с` и `Мбит/с`.
  В таблице по каждому запросу — `Кбит/с`, в итоговой сводке — `Кбит/с` и `Мбит/с`.
- **Объём** — байты и `МБ`.

Скорость = `(объём_в_байтах × 8) / время_в_секундах / 1000` для Кбит/с
(или `/ 1_000_000` для Мбит/с). Агрегатная скорость считается как
`суммарный объём / суммарное время` за весь прогон.

## Пример вывода

```
Целевой URL: https://example.com/big.jpg
Запросов:    10
Таймаут:     30.0 с

[ 1/10]    4194304 байт   0.512 с    65536.00 Кбит/с
[ 2/10]    4194304 байт   0.498 с    67394.13 Кбит/с
...
[10/10]    4194304 байт   0.507 с    66188.29 Кбит/с

--- Итог ---
Успешных запросов:     10/10
Среднее время запроса: 0.505 с
Всего скачано:         41943040 байт (41.94 МБ)
Скорость скачивания:   66463.42 Кбит/с (66.463 Мбит/с)
```

При сбое отдельного запроса вместо строки с замерами выводится, например:

```
[ 3/10] ОШИБКА: <urlopen error timed out>
```

Такой запрос не учитывается в статистике, но попадает в счётчик `с ошибкой: N`.
